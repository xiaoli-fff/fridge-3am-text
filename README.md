A smart fridge texts its owner at 3am after humming nonstop for six years so the leftovers could sleep.

## Run it

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
