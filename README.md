One original line for the make.fun 3AM Fridge Text bounty: the message a smart fridge sends its owner at 3am, after humming nonstop for six years so the leftovers could sleep.

## Run it

```sh
node main.ts
```

The program writes the entry to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
